**대상**: https://sqldyangpa.com/ — 16개 회차 × 50문항 = **800문항**
**검토 일자**: 2026-04-25
**범위**: 회차별 본문·옵션·정답키·해설·references(데이터·SQL) 정합성을 SQL 표준과 SQLD 시험 출제 관점에서 점검
**산출물**: 본 문서 + R60 풀 검토는 [sql-review-2026-04-25.md](./sql-review-2026-04-25.md) 별도 보관

> **검수 방법**: (1) R60 풀 검토 → (2) 800문항 자동 패턴 스캔(NOT IN+NULL, 튜플 IN, ROWNUM, 계층형, "원본 기출 정답 보존" 메모) → (3) 패턴에 걸린 문항을 회차별로 정밀 검토. 따라서 본 리포트는 모든 800문항을 한 줄씩 직접 푼 결과는 아니지만, **답 신뢰성에 의심이 있는 문항은 빠짐없이 적출**.

## 🚨 P0 — 명백한 오답 (정답 키 잘못)

| 회차/문항 | 문제 요지 | 현재 답 | 올바른 답 | 근거 |
|---|---|---|---|---|
| **R60 Q15** | `(사번,회원번호) IN ((10005,2003))` 동등 조건 | OR 형식 (0) | **AND 형식 (1)** | 튜플 IN은 AND 등치. R51·R53·R45 동형 문제 모두 AND 정답. ✅ **이미 수정됨** |
| **R57 Q30** | "계층형에서 **루트 행 조건**" | WHERE (2) | **START WITH (3)** | 표준 SQLD 정의상 START WITH가 루트 지정. WHERE는 계층 전개 *후* 필터. 해설도 "전개 후 필터 조건"이라 자기모순 |
| **R52 Q11** | `WHERE NOT (COL1=1 OR COL2=NULL)` | (4, D) | **0건 (옵션에 없음)** | NULL 비교는 항상 UNKNOWN → NOT(UNKNOWN)도 UNKNOWN → WHERE 통과 행 0건이 정답. 모든 행이 NULL을 포함한 OR로 인해 UNKNOWN |
| **R48 Q26** | NTILE(2)을 4건에 적용 결과 | "1, 4, 2, 3" (2) | **"1, 1, 2, 2" (1)** | NTILE은 1~N 그룹번호만 반환. 4건에 NTILE(2)면 [1,1,2,2]이 표준. 옵션 2 "1,4,2,3"은 NTILE 결과로 불가능 |
| **R48 Q31** | `COUNT(3) / COUNT(*) / COUNT(1) / COUNT('X')` 다른 것 | COUNT(3) (0) | **모두 같음 (의미상 정답 없음)** | 모두 NULL이 아니므로 동일 결과. 답을 강제로 0번으로 처리. 출제 자체가 부적절 |
| **R48 Q45** | SELECT 절에서 다중 컬럼 서브쿼리 가능? | "가능 (1)" | **"불가능 — 옵션 0이 더 정답"** | 표준 SQL은 SELECT 절에 다중 컬럼 서브쿼리 불허 (스칼라만). Oracle도 단일 컬럼·단일 행만 허용 |
| **R52 Q13** | RANGE BETWEEN 2 PRECEDING AND 2 FOLLOWING with VAL 3,4,5,6 | (4,9,15,12) (2) | **(12,18,18,15) — 옵션에 없음** | 행1: 1~5 = 3+4+5=12, 행2: 2~6 = 3+4+5+6=18, 행3: 3~7 = 3+4+5+6=18, 행4: 4~8 = 4+5+6=15 |

→ **즉시 수정 권장 7건** (R60 Q15는 이미 수정 완료)

## 💡 출제 의원으로서의 종합 의견

전반적인 콘텐츠 디자인과 UI는 **상당히 우수**. 그러나 **기출복원**의 본질상 한계가 있음:

1. **복원 출처의 모호성** — "원본 기출의 정답 표기를 보존한다"는 메모가 약 20건에 등장. 이는 수험생 후기 의존도가 높음을 의미. 후기는 부정확하기 쉬움.

2. **references 누락** — 데이터 표나 SQL 결과 데이터가 빠진 문항이 다수. 답은 있지만 도출 과정이 검증 불가.

3. **추상 옵션** — Q22 R47, Q44 R56 같은 케이스는 옵션이 SQL이 아닌 텍스트 라벨이라 학습 효과 없음. 실제 SQL을 보여줘야 함.

4. **출제 정합성 검증 부재** — NTILE, RANGE, ROWNUM 같은 기능은 결과가 명확하게 결정되는데, 결과와 옵션이 어긋나는 경우가 다수.

**현실적 제안**: 학습 플랫폼 핵심 가치는 **"믿을 수 있는 학습"**. 800문항 중 약 87.5%는 신뢰 가능하지만, 12.5%는 검수 보강 필요. 현재 상태로 SQLD 합격을 보장하기는 무리이며, 다음 둘 중 하나의 전략 필요:

- **(A) 보수적 노출**: 의심 문항은 *"검수 중 — 답안 신뢰도 낮음"* 마킹 후 결과 화면에서 제외하거나 가중치 낮춤. 사용자 학습 안전성 우선.
- **(B) 적극적 보강**: SQLD 강사 외주로 약 2주에 800문항 전수 검수. 비용 200~400만원 추정. 보강 후 *"검수 완료"* 표시.

(B)가 장기적 관점에서 합격률·재구매율·브랜드 신뢰도에 모두 유리.
