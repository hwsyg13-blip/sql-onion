핵심 요약 정의

WHERE 절은 어떤 행만 가져올지 조건을 거는 필터다. 테이블 전체에서 원하는 행만 골라낸다.
옷가게에서 "검은색(= '검정')·5만원 이하(<= 50000)·M 또는 L 사이즈(IN ('M','L'))"라고 조건을 거는 것과 같다.

AND · OR · NOT 의 집합 의미

두 조건 A, B를 두 원으로 그렸을 때 각 논리 연산자가 가리키는 영역.

A AND B
교집합 — A와 B 둘 다 참
A OR B
합집합 — 둘 중 하나 이상 참
NOT A
여집합 — A가 아닌 영역

LIKE 연산자의 와일드카드

기호의미예
%0개 이상의 문자'김%' → '김', '김철수', '김OO'
_정확히 1개 문자'김_수' → '김철수', '김영수'
 
-- 김으로 시작
SELECT * FROM EMP WHERE NAME LIKE '김%';

-- 정확히 3글자, 가운데가 '철'
SELECT * FROM EMP WHERE NAME LIKE '_철_';

-- 와일드카드 자체를 검색하려면 ESCAPE
SELECT * FROM ITEM WHERE NAME LIKE '%50\%%' ESCAPE '\';

NULL 비교

잘못된 표현올바른 표현
WHERE COL = NULLWHERE COL IS NULL
WHERE COL != NULLWHERE COL IS NOT NULL

NULL과의 비교는 항상 UNKNOWN이 되어 결과가 비어버린다. 자세한 배경은 NULL 속성의 이해 참고.

연산자 우선순위

1. 산술 ( *, /, +, - )
2. 연결 ( || )
3. 비교 ( =, <, > 등)
4. NOT
5. AND
6. OR

AND가 OR보다 먼저 처리된다. A OR B AND C = A OR (B AND C).

-- 의도: 부서가 D1이거나 D2 이면서 급여 3000 이상
-- 잘못된 예
WHERE DEPT = 'D1' OR DEPT = 'D2' AND SAL >= 3000
-- AND 먼저 해석되어 D1 또는 (D2 AND SAL>=3000)이 됨

-- 올바른 예
WHERE (DEPT = 'D1' OR DEPT = 'D2') AND SAL >= 3000

SQL 실전 연산자별 사용 예 

-- 비교
SELECT * FROM EMP WHERE SAL >= 3000;

-- BETWEEN
SELECT * FROM EMP WHERE SAL BETWEEN 3000 AND 5000;

-- IN
SELECT * FROM EMP WHERE DEPT_ID IN ('D1', 'D2', 'D3');

-- LIKE
SELECT * FROM EMP WHERE NAME LIKE '김%';

-- IS NULL
SELECT * FROM EMP WHERE COMM IS NULL;

-- AND/OR
SELECT * FROM EMP WHERE DEPT_ID = 'D1' AND SAL >= 3000;

WHERE는 행을 하나씩 검사해 조건이 TRUE인 행만 통과시키므로, 조건 표현이 곧 결과 집합이 된다. NULL 비교는 항상 UNKNOWN이 되어 =·!=로는 잡히지 않으니 IS NULL을 써야 하고, IN으로 부서 다중 선택과 비교 연산자를 AND로 묶는 식으로 조건을 세분화하면 된다. "정확히 어떤 행이 필요한가"를 먼저 말로 풀어쓴 뒤 그것을 그대로 연산자로 옮기면 실수가 줄어든다.
