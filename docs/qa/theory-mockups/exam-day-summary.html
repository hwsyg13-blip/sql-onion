시험 당일 핵심 총정리

시험 직전 5~10분 통독용. 챕터별 한 줄 정리 · 빈출 함정 TOP 30 · 명령어 분류 · 당일 체크리스트

바로가기 챕터 정리 빈출 함정 30 명령어 분류 당일 체크

1챕터별 30초 정리

1과목 — 데이터 모델링의 이해

1-1-1 데이터 모델
개념 → 논리 → 물리. 정규화는 논리 단계.
1-1-2 엔터티
5대 특징 업·식·인·속·관. 인스턴스 ≥ 2, 속성 ≥ 2.
1-1-3 속성
기본·설계·파생. 한 컬럼 한 값(원자성).
1-1-4 관계
1:1 / 1:N / M:N(분해 필요). 식별/비식별.
1-1-5 식별자
4대 조건 유·최·불·존. PK = UNIQUE + NOT NULL.
1-2-1 정규화
1NF→2NF→3NF→BCNF. 부분종속=2NF / 이행종속=3NF.
1-2-2 관계와 조인
관계 = FK = JOIN의 토대.
1-2-3 트랜잭션
ACID — 원자성·일관성·고립성·지속성.
1-2-4 NULL
= NULL 안 됨, IS NULL만. NULL+값=NULL. COUNT(*)만 NULL 포함.
1-2-5 본질·인조 식별자
본질=업무 키, 인조=대리키(SEQ). 인조는 모델 가독성↓.

2과목 — SQL 기본 (2-1)

2-1-1 RDB 개요
DDL/DML/DCL/TCL. TRUNCATE=DDL, DELETE=DML.
2-1-2 SELECT문
작성 SFWGHO / 실행 FWGHSO(FROM→WHERE→GROUP→HAVING→SELECT→ORDER).
2-1-3 함수
단일행/다중행. NVL · NVL2 · NULLIF · COALESCE.
2-1-4 WHERE절
AND > OR. BETWEEN 양 끝 포함. LIKE _=1글자, %=0+.
2-1-5 GROUP BY/HAVING
WHERE는 집계 전, HAVING은 집계 후.
2-1-6 ORDER BY
Oracle ASC NULL 마지막, MS-SQL ASC NULL 처음.
2-1-7 조인
EQUI/Non-EQUI/SELF/OUTER/CROSS. OUTER 조건은 ON에.
2-1-8 표준 조인
NATURAL=같은 이름·타입 자동, USING=컬럼 명시.

2과목 — SQL 활용 (2-2)

2-2-1 서브쿼리
스칼라/인라인뷰/연관. ANY=최소 / ALL=최대.
2-2-2 집합 연산자
UNION 정렬·중복제거, UNION ALL 그대로. INTERSECT, MINUS.
2-2-3 그룹 함수
ROLLUP N+1단계 / CUBE 2^N. GROUPING SETS는 골라보기.
2-2-4 윈도우 함수
RANK(건너뜀) vs DENSE_RANK(연속). PARTITION BY로 그룹별.
2-2-5 Top N
ROWNUM 정렬 전 매겨짐. FETCH FIRST는 12c+, WITH TIES.
2-2-6 계층형 질의
START WITH ... CONNECT BY PRIOR. LEVEL 의사컬럼.
2-2-7 PIVOT/UNPIVOT
세로↔가로. PIVOT 집계 필수, UNPIVOT NULL 기본 제외.
2-2-8 정규 표현식
REGEXP_LIKE/REPLACE/SUBSTR/INSTR/COUNT.

2과목 — 관리 구문 (2-3)

2-3-1 DML
INSERT/UPDATE/DELETE/MERGE. ROLLBACK 가능.
2-3-2 TCL
COMMIT/ROLLBACK/SAVEPOINT. ROLLBACK TO SP.
2-3-3 DDL
CREATE/ALTER/DROP/TRUNCATE/RENAME. 자동 COMMIT.
2-3-4 DCL
GRANT/REVOKE. WITH GRANT OPTION(객체) / WITH ADMIN OPTION(시스템).

2빈출 함정 TOP 30

출제 빈도 높은 함정 위주. 함정 → 정답·이유 한 줄.

01NULL = NULL의 결과는 UNKNOWN(FALSE 아님). WHERE에서는 행 제외.
02WHERE COL = NULL → 결과 0건. 반드시 IS NULL 사용.
03NULL + 100 = NULL. NULL과의 산술은 모두 NULL.
04AVG(컬럼)의 분모는 NULL 제외 개수. 0 포함 평균과 다름.
05COUNT(*)는 NULL 포함 / COUNT(컬럼)은 NULL 제외.
06ROWNUM은 정렬 전 매겨짐. 인라인뷰로 정렬 먼저.
07ROWNUM = 5 → 결과 0건. ROWNUM ≤ N 또는 = 1만 가능.
08ROWNUM > N → 항상 거짓(결과 0건).
09TRUNCATE=DDL. 자동 COMMIT, ROLLBACK 불가, 매우 빠름.
10DELETE=DML. ROLLBACK 가능, WHERE 가능.
11DDL은 실행 즉시 자동 COMMIT. 펜딩 트랜잭션도 같이 커밋.
12SELECT 실행 순서 = FROM → WHERE → GROUP → HAVING → SELECT → ORDER(FWGHSO).
13OUTER JOIN 조건은 ON에. WHERE에 두면 NULL 행이 제외돼 INNER 효과.
14NATURAL JOIN: 같은 이름·타입 컬럼 자동 조인. 이름 같고 타입 다르면 에러.
15CROSS JOIN: 조인 조건 누락 시 카티션 곱. 의도치 않으면 위험.
16RANK(1,1,3,4) vs DENSE_RANK(1,1,2,3) — RANK는 동률 다음 순위 건너뜀.
17정규화: 부분종속 → 2NF / 이행종속 → 3NF.
18엔터티 조건: 인스턴스 ≥ 2, 속성 ≥ 2.
19PK = UNIQUE + NOT NULL, 1개만. UNIQUE는 NULL 허용, 여러 개 가능.
20FK는 부모의 PK 또는 UNIQUE 컬럼만 참조 가능.
21DECODE는 동등비교만(=). CASE는 범위·논리 가능.
22NVL2(A,B,C) — A NOT NULL → B / NULL → C.
23NULLIF(A,B) — A=B면 NULL, 아니면 A.
24COALESCE(...) — NULL이 아닌 첫 값 반환.
25ROLLUP(A,B): N+1 = 3단계 — (A,B), (A), ().
26CUBE(A,B): 2^N = 4단계 — 모든 조합.
27UNION은 정렬+중복제거(느림), UNION ALL은 그대로(빠름).
28ROLLBACK TO SP1 → SP1 이후 작업만 취소. 이전 작업은 유지.
29GROUP BY 사용 시 SELECT의 일반 컬럼은 GROUP BY에 명시 필수(집계 함수는 예외).
30ANY=최소값 기준(작아도 됨) / ALL=최대값 기준(가장 커야 됨).

주의 — 시험에 단골

!TRUNCATE는 DDL(DML 아님) — 자동 COMMIT, ROLLBACK 불가, WHERE 불가.
!DELETE는 DML(DDL 아님) — ROLLBACK 가능, WHERE 가능, 느림.
!DROP은 객체 자체 제거. TRUNCATE는 데이터만 비우고 구조 유지.
!DCL GRANT도 자동 COMMIT (별도 COMMIT 불필요).
