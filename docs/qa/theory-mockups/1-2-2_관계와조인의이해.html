관계와 조인의 이해

관계 → 외래키(FK) → 조인(JOIN). 흩어진 데이터를 키로 합치는 흐름

핵심 요약 정의

모델에서의 관계는 외래키(FK)로 구현되고, 그 관계를 따라 여러 테이블을 합쳐 보는 작업이 조인(JOIN)이다.
영수증에는 주문 정보만, 회원카드에는 회원 정보만 있다. 같은 사람의 영수증과 카드를 맞춰 보면 "김철수가 사과 2개 샀구나"가 보인다 — 흩어진 정보를 키로 맞춰 합치는 것이 조인이다.

개념 도식화 관계 → FK → JOIN

①
관계 설계 단계 · 개념 모델
두 엔터티 사이의 의미적 연결("회원이 주문을 한다")을 ERD 선으로 표현
▼
②
외래키 (FK) 구현 단계 · 논리/물리 모델
자식 테이블이 부모 테이블의 PK를 참조하는 컬럼. FK = 조인 키
▼
③
조인 (JOIN) 조회 단계 · SQL 실행
FK = PK 조건으로 두 테이블을 합쳐 한 결과로 보는 SQL 동작

자식 테이블의 FK가 곧 조인 키다. 예: MEMBER(MEMBER_ID PK) ↔ ORDERS(MEMBER_ID FK).

erDiagram MEMBER ||--o{ ORDERS : "필수1 - 선택N" MEMBER { varchar MEMBER_ID PK varchar NAME } ORDERS { number ORDER_ID PK varchar MEMBER_ID FK date ORD_DATE }

표기: ||--o{ = "회원은 항상 1명, 주문은 0개 이상" (회원에 필수, 주문은 선택). 식별 관계는 ||--|{.

조인의 4가지 종류 — 개념 미리보기

종류의미비유
INNER JOIN양쪽에 다 있는 것만양쪽 카드 모두 가진 사람
LEFT OUTER왼쪽 다, 오른쪽은 매칭만왼쪽 기준, 오른쪽 없으면 NULL

자세한 구문은 조인 / 표준 조인에서 다룬다.

INNER JOIN
교집합 — 양쪽 매칭 행만
LEFT OUTER
왼쪽 다 + 매칭, 미매칭은 NULL
RIGHT OUTER
오른쪽 다 + 매칭, 미매칭은 NULL
FULL OUTER
합집합 — 한쪽만 있어도 모두

관계의 종류와 조인 시 주의점

1:1
단순 매칭
[사원] 1 ── 1 [사원증]
사원 한 명당 사원증 한 개 → 행 수 그대로
1:N
행이 늘어남
[회원] 1 ── N [주문]
회원 1명에 주문 3건이면 결과 3행
M:N
교차 엔터티 필요
학생 M─N 과목 → 수강 거쳐 두 번 조인

1:1 관계 — 단순 매칭

INNER JOIN 결과: 사원 한 명당 사원증 한 개 → 사원 행 수 그대로 유지. (사원증이 없는 사원은 LEFT JOIN을 써야 결과에 남음)

1:N 관계 — 행이 늘어남

회원 1명에게 주문이 3건이면 조인 후 3행으로 늘어난다.

M:N 관계 — 교차 엔터티 필요

[학생] M ── N [과목]    →    [학생] 1─N [수강] N─1 [과목]

조인은 반드시 수강(교차)을 거쳐 두 번 한다.

영어
-- 1:N 조인: 회원과 주문
SELECT  M.NAME, O.ORDER_ID, O.ORD_DATE
FROM    MEMBER M
        JOIN ORDERS O ON M.MEMBER_ID = O.MEMBER_ID;

-- M:N → 교차 테이블 거쳐 두 번 조인
SELECT  S.NAME AS STUDENT, K.NAME AS SUBJECT, R.GRADE
FROM    STUDENT  S
        JOIN REGISTER R ON S.STU_ID = R.STU_ID
        JOIN SUBJECT  K ON R.SUB_ID = K.SUB_ID;

회원 2명이지만 주문이 3건이므로 결과는 3행이다. 1:N 조인의 결과 행 수는 부모(1쪽) 수가 아니라 자식(N쪽) 수에 맞춰 결정된다 — 부모 한 행이 매칭된 자식 수만큼 복제된다고 보면 된다. 이 사실을 잊고 부모 컬럼(예: 회원 등급별 포인트)을 그대로 SUM 하면 자식 수만큼 부풀려진 합계가 나온다. 1:N 조인 후 부모 쪽 집계가 필요하면 자식 합계를 서브쿼리로 먼저 구해 1:1로 만들어 붙이는 것이 안전하다.

조인의 방향성

일반적으로 PK(부모) ← FK(자식) 방향으로 조인한다.

[부서] PK ←─── FK [사원]
   조인 키 = 부서.PK = 사원.FK
