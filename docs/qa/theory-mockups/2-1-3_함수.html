단일행 vs 다중행(집계) · 문자/숫자/날짜/변환/NULL · CASE·DECODE

핵심 요약 정의

함수는 데이터를 입력받아 가공된 결과를 돌려주는 도구다. 문자, 숫자, 날짜, NULL을 가공할 수 있다.

개념 도식화 함수의 분류 — 단일행(1행→1결과) / 다중행(N행→1결과)

NULL 관련 함수

NVL(A, B)
A가 NULL이면 B로 대체
NVL(SAL, 0)
NVL2(A, B, C)
A가 NULL 아니면 B, NULL이면 C
NVL2(COMM, '있음', '없음')
NULLIF(A, B)
A=B면 NULL, 아니면 A
NULLIF(A, 0)
COALESCE(A, B, …)
NULL이 아닌 첫 값 반환
COALESCE(P1, P2, '없음')

UPPER — 대문자 변환 (문자)

SELECT UPPER('sqld') AS RESULT FROM DUAL;

↓ 결과

RESULT
SQLD

→ 입력 문자열의 모든 알파벳이 대문자로 변환된다.

ROUND — 반올림 (숫자)

SELECT ROUND(3.456, 1) AS RESULT FROM DUAL;

↓ 결과

RESULT
3.5

→ 두 번째 인자 1은 소수 1자리까지 남기겠다는 뜻. 3.456 → 3.5.

TO_CHAR — 날짜→문자 변환

SELECT TO_CHAR(SYSDATE, 'YYYY-MM-DD') AS TODAY FROM DUAL;

↓ 결과

TODAY
2026-04-27

→ 날짜 타입을 'YYYY-MM-DD' 포맷에 맞춰 문자열로 변환한다.

NVL — NULL 대체

SELECT NAME, NVL(COMM, 0) AS COMM_FIX FROM EMP;

↓ 결과 (B는 COMM이 NULL)

NAMECOMM_FIX

→ B의 COMM이 NULL이어서 NVL(COMM, 0)이 0으로 대체했다.

SQL 실전 조건 함수 — CASE / DECODE 

-- DECODE (Oracle 전용, 동등비교만 가능)
SELECT NAME,
       DECODE(GENDER, 'M', '남자', 'F', '여자', '기타') AS GENDER_KOR
FROM   MEMBER;

-- CASE (표준, 모든 비교 가능)
SELECT NAME,
       CASE WHEN SAL >= 5000 THEN '고급'
            WHEN SAL >= 3000 THEN '중급'
            ELSE '초급'
       END AS GRADE
FROM   EMP;

다중행(집계) 함수

여러 행을 묶어 하나의 결과로 요약한다. 자세한 분석은 그룹함수 챕터 참고. 보통 WHERE 이후의 GROUP BY와 함께 쓰인다.

함수의미NULL 처리
COUNT(*)모든 행 수NULL 포함
COUNT(col)컬럼 NULL 제외NULL 제외
SUM(col)합NULL 무시
AVG(col)평균NULL 무시
MAX(col)최대NULL 무시
MIN(col)최소NULL 무시

Before & After 함수 활용

EMP의 NAME(소문자), HIRE_DATE(날짜형), SAL+COMM(NULL 가능)을 한 번에 가공해야 하는 상황. 김철수는 COMM이 NULL이고 이영희는 200인데, 문자·날짜·NULL 함수를 결합해 "대문자 이름 / 입사연도 / 총급여"를 동시에 뽑는다.

UPPER는 문자형, TO_CHAR(HIRE_DATE,'YYYY')는 날짜→문자, NVL(COMM,0)은 NULL 안전 산술처럼 함수마다 다루는 도메인이 다르다. NVL을 빼면 김철수의 TOTAL이 NULL로 사라지는 사고가 그대로 발생하므로, 출력 형식·표시 단위·NULL 처리를 모두 함수 단계에서 정리하고 SELECT 결과는 화면에 바로 쓸 수 있는 형태로 만드는 것이 안전하다.
