정규 표현식 (Regular Expression)

LIKE보다 강력한 패턴 검색 · 5개 함수 · 메타문자 · 문자 종류·길이·위치 동시 검사

핵심 요약 정의

정규 표현식은 문자 패턴을 표현하는 짧은 식이다. LIKE보다 훨씬 강력하게 문자열을 검색·추출·교체할 수 있다.
LIKE는 "'김%'로 시작" 정도지만, 정규식은 "010-숫자4자리-숫자4자리" / "한글 3글자 이름" / "이메일 형식" 같은 정밀 패턴을 표현한다.

-- 휴대폰 번호 형식 (010으로 시작, 3-4-4 자리)

FROM   MEMBER
WHERE  REGEXP_LIKE(PHONE, '^010-\d{3,4}-\d{4}$');

FROM   MEMBER
WHERE  REGEXP_LIKE(EMAIL, '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$');

-- 한글 3글자 이름
SELECT *
FROM   MEMBER
WHERE  REGEXP_LIKE(NAME, '^[가-힣]{3}$');

REGEXP_REPLACE (교체)

-- 모든 공백 제거
SELECT REGEXP_REPLACE('Hello   World', '\s+', '') FROM DUAL;
-- 결과: 'HelloWorld'

-- 전화번호 가운데를 마스킹
SELECT REGEXP_REPLACE('010-1234-5678', '(\d{3})-(\d{4})-(\d{4})', '\1-****-\3') FROM DUAL;
-- 결과: '010-****-5678'

↓ 결과

입력패턴 → 치환결과
'Hello World'\s+ → ''HelloWorld
'010-1234-5678'(\d{3})-(\d{4})-(\d{4}) → \1-****-\3010-****-5678

REGEXP_SUBSTR (추출)

-- 첫 번째 숫자 묶음 추출
SELECT REGEXP_SUBSTR('주문번호 12345 입니다', '\d+') FROM DUAL;
-- 결과: '12345'

↓ 결과

입력패턴추출 결과
'주문번호 12345 입니다'\d+12345
'no-digits'\d+NULL
'abc 12 def 34'\d+12 (첫 매치만)

REGEXP_INSTR / REGEXP_COUNT

-- 처음 숫자가 나타나는 위치
SELECT REGEXP_INSTR('abc123def', '\d') FROM DUAL;  -- 4

-- 단어 개수
SELECT REGEXP_COUNT('one two three', '\w+') FROM DUAL;  -- 3

↓ 결과

함수입력 / 패턴결과
REGEXP_INSTR'abc123def' / \d4 (1-based)
REGEXP_INSTR'no digits' / \d0 (없음)
REGEXP_COUNT'one two three' / \w+3
REGEXP_COUNT'aaaa' / a4

Before & After LIKE로는 까다로운 두 조건

MEMBER 3건에서 "한글 이름이고 동시에 010 휴대폰 번호인 회원"만 골라내야 하는 상황. 2번은 휴대폰이 02 지역번호라 떨어지고, 3번은 이름이 영문이라 떨어진다. LIKE 두 개로는 표현하기 까다로운 두 조건을 REGEXP_LIKE로 정밀하게 거른다.

^[가-힣]+$는 문자열 처음(^)부터 끝($)까지가 모두 한글 한 글자([가-힣])의 1회 이상 반복으로만 채워질 때만 매칭하므로, "Jane"은 영문이라 즉시 탈락하고 김철수·이영희는 통과한다. 다음 조건 ^010-은 PHONE이 정확히 "010-"으로 시작할 때만 통과시키므로 02 지역번호인 이영희가 떨어진다. 두 정규식 조건을 AND로 조합해 "한글 이름 + 010 휴대폰" 교집합만 남는 셈이다. LIKE의 %·_로는 "글자 종류(한글)"를 표현할 수 없으니, 문자 종류·길이·위치를 동시에 검사해야 할 때는 정규식이 자연스러운 선택이다.
