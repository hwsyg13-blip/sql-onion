엔터티 (Entity)

정보의 덩어리. 5대 특징 · 유무형 분류 · 발생 시점 분류

핵심 요약 정의

엔터티(Entity)란 업무에서 관리해야 할 정보의 덩어리(명사)다. 실제 테이블의 후보가 된다.
쇼핑몰이라면 회원·상품·주문·배송 같은 명사 하나하나가 엔터티이며, 각 엔터티의 개별 사례(예: '김철수 회원')를 인스턴스(Instance, 한 행) 라고 부른다.

CREATE TABLE MEMBER (
    MEMBER_ID    VARCHAR2(10) PRIMARY KEY,  -- 식별자
    NAME         VARCHAR2(50),
    PHONE        VARCHAR2(20),
    JOIN_DATE    DATE
);

-- 인스턴스(행) 입력
INSERT INTO MEMBER VALUES('M01', '김철수', '010-1111', DATE '2026-01-15');
INSERT INTO MEMBER VALUES('M02', '이영희', '010-2222', DATE '2026-02-08');

-- 조회
SELECT MEMBER_ID, NAME FROM MEMBER;

↓ 결과

MEMBER_IDNAME
M01김철수
M02이영희

→ SELECT 문이 두 인스턴스(M01·M02)에서 두 속성(MEMBER_ID·NAME)만 골라 보여준다.

엔터티(설계 단계) → 테이블(SQL 단계) → 행(인스턴스)으로 단계가 매핑된다.
