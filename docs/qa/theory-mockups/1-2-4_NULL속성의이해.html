NULL 속성의 이해

값 없음. IS NULL로만 비교 · 3-값 논리 · NULL 처리 함수

핵심 요약 정의

NULL이란 값이 없거나 아직 모름을 나타내는 특수한 표시다. 0이나 공백과는 전혀 다르다.
설문지에서 "월 소득: 0원"은 0이라는 값이 적힌 것, "월 소득: ␣"(한 칸 띈 상태)은 공백 문자, "월 소득: 미작성"이 NULL(값 자체가 없음)이다.

NULL의 4가지 규칙

1
산술 연산
결과는 NULL
1000 + NULL = NULL
2
비교 연산
결과는 UNKNOWN (3-값 논리). WHERE 절에서 행 제외
3
IS NULL / IS NOT NULL
= NULL, != NULL은 항상 거짓
4
집계 함수
NULL을 무시. COUNT(*)만 NULL 포함
SQL 3-값 논리 — 일반 프로그래밍은 TRUE/FALSE 2값이지만 SQL은 NULL 때문에 TRUE / FALSE / UNKNOWN 3값. NULL = NULL도 결과가 UNKNOWN.

WHERE 절은 결과가 TRUE인 행만 남긴다. UNKNOWN은 TRUE가 아니므로 자동 제외 — 그래서 = NULL은 항상 0건.

NULL 처리 함수

자세한 동작은 함수 챕터에서도 다룬다.

NVL(A, B)
A가 NULL이면 B로 대체
NVL(SAL, 0)
NVL2(A, B, C)
A가 NULL 아니면 B, NULL이면 C
NVL2(COMM, '있음', '없음')
NULLIF(A, B)
A=B면 NULL, 아니면 A
NULLIF(A, 0)
COALESCE(A, B, C, …)
NULL이 아닌 첫 값 반환
COALESCE(P1, P2, '없음')

집계 함수에서의 NULL

함수NULL 처리

SUM/AVG/MAX/MINNULL 무시
AVG(컬럼)(NULL 제외 합) / (NULL 제외 개수)

-- 잘못된 비교
SELECT * FROM EMP WHERE COMM = NULL;     -- 결과 0건
SELECT * FROM EMP WHERE COMM != NULL;    -- 결과 0건

-- 올바른 비교
SELECT * FROM EMP WHERE COMM IS NULL;
SELECT * FROM EMP WHERE COMM IS NOT NULL;

-- NULL 대체
SELECT NAME, NVL(COMM, 0) AS COMM_FIX FROM EMP;
SELECT NAME, NVL2(COMM, '있음', '없음') AS FLAG FROM EMP;
SELECT NAME, COALESCE(PHONE, EMAIL, '연락처 없음') FROM MEMBER;

NULL은 산술 연산에 들어가면 결과 전체를 NULL로 만든다. B처럼 커미션이 비어 있을 뿐인 직원의 총급여까지 사라져버리는 셈이다. NVL(COMM, 0)으로 "커미션 없음 = 0"으로 안전하게 치환하면, NULL 행도 정상 합산되어 보고서에 누락이 생기지 않는다. 합계·평균 같은 집계 전에는 늘 NULL을 어떻게 다룰지 정해두는 것이 안전하다.
