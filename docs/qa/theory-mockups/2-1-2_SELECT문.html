SELECT 문

데이터를 골라 뽑는 6대 절. 작성 순서와 실행 순서(FWGHSO)는 다르다

핵심 요약 정의

SELECT 문은 데이터베이스에서 원하는 데이터를 골라서 뽑아내는 명령어다.
식당 주문처럼 "어느 식당(FROM) · 어떤 음식(SELECT) · 조건(WHERE) · 그룹별(GROUP BY) · 정렬(ORDER BY)"을 차례로 지정한다.

개념 도식화 SELECT 문의 6대 절 

SELECT    컬럼1, 컬럼2, ...      ← ② 어떤 컬럼? (함수 활용)
FROM      테이블                   ← ① 어디서? (조인 가능)
WHERE     조건                     ← ③ 어떤 행?
GROUP BY  그룹기준                 ← ④ 어떻게 묶을지?
HAVING    그룹조건                 ← ⑤ 묶은 후 조건?
ORDER BY  정렬기준;                ← ⑥ 어떻게 정렬?

각 절의 자세한 사용은 WHERE, GROUP BY/HAVING, ORDER BY, 함수, 조인 챕터에서 다룬다.

DISTINCT는 SELECT 절 전체(여러 컬럼이면 컬럼 조합) 단위로 중복을 제거하므로, NAME만 골라보면 동명이인 김철수도 한 줄로 합쳐진다. 반면 SAL*12 같은 표현은 행 단위로 매번 계산되므로 같은 이름이라도 별개 행으로 남는다. "원본 데이터를 그대로 보고 싶다"면 컬럼 나열, "값 종류만 보고 싶다"면 DISTINCT, "가공된 값을 의미있는 이름으로 보고 싶다"면 별칭을 선택하면 된다.

DUAL 테이블 (Oracle)

시스템 내장 가짜 테이블이다. 한 행, 한 컬럼만 있고, 계산이나 함수 결과를 확인할 때 쓴다.

SELECT 1+1 FROM DUAL;        -- 2
SELECT SYSDATE FROM DUAL;    -- 현재 시각
SELECT USER FROM DUAL;       -- 접속 계정
