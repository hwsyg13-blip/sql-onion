서브쿼리 (Sub Query)

쿼리 안의 또 다른 쿼리 · 메인이 사용할 값을 미리 계산해 알려주는 보조 쿼리

핵심 요약 정의

서브쿼리는 쿼리 안에 들어 있는 또 다른 쿼리다. 메인쿼리가 사용할 값을 미리 계산해 알려주는 보조 쿼리다.
"평균 가격보다 비싼 상품"을 찾을 때, 평균을 먼저 계산(서브쿼리)한 뒤 그 값보다 큰 상품을 찾는(메인쿼리) 두 단계 작업.

개념 도식화 서브쿼리의 위치 

SELECT  컬럼들                    ← SELECT 서브쿼리(스칼라)
FROM    (서브쿼리)                 ← FROM 서브쿼리(인라인 뷰)
WHERE   컬럼 = (서브쿼리);         ← WHERE 서브쿼리(대표적)

메인 쿼리 시작
실행 중 서브쿼리 결과가 필요한 자리에 도달
→
STEP 2
서브쿼리 실행
메인이 필요로 하는 값을 계산해 반환
→
STEP 3
메인 쿼리 계속
반환된 값으로 비교/필터/투영을 마무리

다중행 서브쿼리 — IN / ANY / ALL

연산자의미
IN (...)값 중 하나와 같으면
> ANY(...)하나 이상보다 크면 → 최솟값보다 크면 됨
> ALL(...)모두보다 크면 → 최댓값보다 커야 함
EXISTS (...)존재하면 참
 
-- IN
SELECT  *
FROM    EMP
WHERE   DEPT_ID IN (SELECT DEPT_ID FROM DEPT WHERE LOC = 'SEOUL');

-- > ANY: 어느 한 값보다 크면 → 최솟값보다만 크면 됨
SELECT  *
FROM    EMP
WHERE   SAL > ANY (SELECT SAL FROM EMP WHERE DEPT_ID = 'D1');

-- > ALL: 모든 값보다 커야 함 → 최댓값보다 커야 함
SELECT  *
FROM    EMP
WHERE   SAL > ALL (SELECT SAL FROM EMP WHERE DEPT_ID = 'D1');

EXISTS 서브쿼리

-- 주문 내역이 있는 회원만
SELECT  *
FROM    MEMBER M
WHERE   EXISTS (SELECT 1 FROM ORDERS O WHERE O.MEMBER_ID = M.MEMBER_ID);

인라인 뷰 (FROM 절)

-- 부서별 평균 중 평균 4000 이상인 부서
SELECT  *
FROM    (SELECT DEPT_ID, AVG(SAL) AS AVG_SAL
         FROM   EMP
         GROUP BY DEPT_ID) X
WHERE   X.AVG_SAL >= 4000;

연관 서브쿼리

-- 자기 부서 평균보다 많이 받는 사원
SELECT  E.NAME, E.SAL, E.DEPT_ID
FROM    EMP E
WHERE   E.SAL > (SELECT AVG(SAL)
                 FROM   EMP
                 WHERE  DEPT_ID = E.DEPT_ID);   -- E.DEPT_ID는 메인쿼리 참조
특징설명
메인쿼리의 각 행마다 서브쿼리 실행행 수만큼 반복
성능 영향큼. 필요시 조인으로 변환

Before & After 단일행(전체 평균) vs 연관(부서 평균)

비연관(단일행) 서브쿼리는 메인쿼리와 무관하게 한 번만 실행되어 4125라는 한 값을 만들고 모든 행이 그 값과 비교된다. 반면 연관 서브쿼리는 바깥의 E.DEPT_ID를 참조하므로 행마다 평균이 다시 계산된다(D1행은 4000, D2행은 4250 기준). 결과 행 집합은 우연히 같아 보여도 비교 기준은 행마다 달라지는 셈이다. "전체 기준"인지 "그룹 기준"인지에 따라 단일행이냐 연관이냐를 선택해야 한다.
