계층형 질의와 셀프 조인

트리 구조 펼치기 · CONNECT BY · LEVEL · SYS_CONNECT_BY_PATH · SELF JOIN

핵심 요약 정의

계층형 질의는 트리 구조 데이터(예: 조직도)를 위에서 아래로 펼치는 쿼리다. 셀프 조인은 같은 테이블을 자기 자신과 조인하는 것이다.
가족 족보를 "사람ID, 부모ID" 한 테이블에 저장한 뒤 CONNECT BY로 할아버지 → 아버지 → 나 순으로 펼쳐 보는 쿼리.

SQL 실전 계층형 질의 

SELECT  LEVEL,
        LPAD(' ', (LEVEL-1)*4) || NAME AS TREE,
        SYS_CONNECT_BY_PATH(NAME, '/') AS PATH
FROM    EMP
START WITH MGR_ID IS NULL
CONNECT BY PRIOR EMP_ID = MGR_ID;

3        사원/사장/매니저A/사원
2    매니저B/사장/매니저B

ORDER SIBLINGS BY — 형제 정렬

SELECT  LEVEL, NAME
FROM    EMP
START WITH MGR_ID IS NULL
CONNECT BY PRIOR EMP_ID = MGR_ID
ORDER SIBLINGS BY NAME;     -- 형제(같은 LEVEL)끼리만 정렬

일반 ORDER BY는 계층 구조를 망가뜨리므로 ORDER SIBLINGS BY를 사용한다.

SELF JOIN

같은 테이블을 두 번 사용해서 조인한다. 별칭으로 구분한다.

SELECT  E.NAME    AS 사원,
        M.NAME    AS 매니저
FROM    EMP E,  EMP M
WHERE   E.MGR_ID = M.EMP_ID;

표준 방식:

SELECT  E.NAME    AS 사원,
        M.NAME    AS 매니저
FROM    EMP E LEFT JOIN EMP M ON E.MGR_ID = M.EMP_ID;

표준 재귀 쿼리 (참고)

-- ANSI 표준: 재귀 CTE(Common Table Expression)
WITH RECURSIVE EMP_TREE(EMP_ID, NAME, MGR_ID, LV) AS (
    SELECT EMP_ID, NAME, MGR_ID, 1
    FROM   EMP
    WHERE  MGR_ID IS NULL
    UNION ALL
    SELECT E.EMP_ID, E.NAME, E.MGR_ID, T.LV + 1
    FROM   EMP E JOIN EMP_TREE T ON E.MGR_ID = T.EMP_ID
)
SELECT * FROM EMP_TREE;

Oracle 12c 이상 및 다른 DBMS도 지원한다.

Before & After 평면 → 트리

평면 테이블 EMP는 4행이 단순히 나열돼 있을 뿐, 사장-매니저-사원의 위계가 보이지 않는다. CONNECT BY로 MGR_ID 컬럼을 따라 부모-자식 관계를 펼치면 같은 4행이 트리 순서로 재배열되고 LEVEL이 1·2·3으로 매겨지는 상황을 비교한다.

START WITH MGR_ID IS NULL이 사장(E1)을 루트로 잡고, CONNECT BY PRIOR EMP_ID = MGR_ID가 "현재 행의 EMP_ID = 다음 행의 MGR_ID"라는 부모-자식 규칙을 정의해 깊이 우선으로 트리를 펼친다. 그래서 매니저A 다음에 그 자식인 사원이 먼저 따라붙고, 그다음에야 매니저B가 출력된다(매니저B 자식이 없으면 거기서 가지 끝). 셀프 조인이라면 "사원-매니저" 1단계만 가능하지만, 계층형 질의는 깊이가 깊어져도 LEVEL과 SYS_CONNECT_BY_PATH로 재귀 추적이 가능하다는 점이 결정적인 차이다.
