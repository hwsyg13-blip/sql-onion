ORDER BY 절

결과 정렬 · ASC/DESC · 컬럼명·별칭·번호 모두 가능 · NULL 위치는 DBMS별 다름

핵심 요약 정의

ORDER BY는 결과를 어떤 순서로 보여줄지 정렬하는 절이다. SELECT 문에서 가장 마지막에 실행된다.
책장 정리처럼 "가나다순(ASC)·최신순(DESC)·분야별 → 분야 내 가나다순(ORDER BY 분야, 책이름)" 식으로 1차·2차 정렬이 가능하다.

개념 도식화 ORDER BY의 위치 

SELECT  ...
FROM    ...
WHERE   ...
GROUP BY ...
HAVING  ...
ORDER BY ...   ← 항상 맨 마지막

ORDER BY는 SELECT 다음에 실행되는 가장 마지막 단계다. 그래서 SELECT에서 만든 별칭과 컬럼 번호를 사용할 수 있다.

ASC vs DESC

ASC (기본)
오름차순
작 → 큰, ㄱ → ㅎ, 1 → 9 · 생략 시 ASC
DESC
내림차순
큰 → 작 · 명시 필수
ORDER BY SAL          -- ASC(기본)
ORDER BY SAL ASC      -- 명시
ORDER BY SAL DESC     -- 내림차순

정렬 기준 작성 방법 3가지

1
컬럼명
ORDER BY SAL DESC
2
별칭(Alias)
ORDER BY ANNUAL_SAL DESC
3
N번째 컬럼(정수)
ORDER BY 2 DESC
SELECT NAME, SAL FROM EMP
-- 방법 1: 컬럼명
ORDER BY SAL DESC;

-- 방법 2: SELECT 별칭(Alias)
SELECT NAME, SAL*12 AS ANNUAL_SAL FROM EMP
ORDER BY ANNUAL_SAL DESC;

-- 방법 3: SELECT의 N번째 컬럼(정수)
SELECT NAME, SAL FROM EMP
ORDER BY 2 DESC;        -- 2번째 컬럼 = SAL

ORDER BY는 SELECT 다음에 실행되므로 별칭 사용이 가능하다(WHERE, GROUP BY는 불가).

비교 NULL의 정렬 순서 — DBMS별

NULL은 비교 불가 값이므로 정렬에서도 DBMS마다 다르게 처리된다.

Oracle
ASC = NULL 마지막
DESC = NULL 처음
"비어있는 값은 뒤로"
MS-SQL
ASC = NULL 처음
DESC = NULL 마지막
Oracle과 정반대
DBMSASC 기본DESC 기본
OracleNULL이 마지막NULL이 처음
MS-SQL ServerNULL이 처음NULL이 마지막

명시적 지정:

ORDER BY COMM ASC NULLS FIRST   -- NULL 먼저
ORDER BY COMM ASC NULLS LAST    -- NULL 마지막

SQL 실전 정렬 패턴 

-- 단일 컬럼
SELECT NAME, SAL FROM EMP
ORDER BY SAL DESC;

-- 다중 컬럼
SELECT NAME, DEPT_ID, SAL FROM EMP
ORDER BY DEPT_ID, SAL DESC;

-- 별칭으로
SELECT NAME, SAL*12 AS YEAR_SAL FROM EMP
ORDER BY YEAR_SAL DESC;

-- 컬럼 번호로
SELECT NAME, DEPT_ID, SAL FROM EMP
ORDER BY 3 DESC, 2 ASC;

부서 오름차순 → 부서 내 급여 내림차순으로 정렬되었다. ORDER BY는 나열된 컬럼 순서대로 1차·2차·3차 정렬을 적용하고, ASC/DESC는 컬럼별로 따로 지정된다. 따라서 "DEPT_ID는 오름차순, SAL은 내림차순"처럼 키마다 방향이 달라도 한 줄에 함께 쓸 수 있다. 결과 순서를 사람 눈에 보일 형태로 확정해야 하는 보고서·페이지네이션·TopN 쿼리에서는 정렬 키를 의도대로 명시해두는 것이 안전하다.

ORDER BY 주의사항

ORDER BY는 정렬된 상위 N개만 추출하는 TopN 쿼리의 기반이 된다.

주의설명
항상 맨 끝UNION 등 집합연산자 사용 시도 마지막에 한 번만
숫자 정렬1, 2, 10... 숫자 그대로
문자 정렬'1', '10', '2'... 사전순 → 1, 10, 2
NULL 위치DBMS별로 다름. 명시 권장
인덱스 활용정렬 작업에 인덱스가 활용될 수 있음
