조인(JOIN)

두 테이블을 키로 연결 · EQUI / Non-EQUI / SELF / OUTER / CROSS · 조건 누락은 카티션 곱

핵심 요약 정의

조인은 두 개 이상의 테이블을 키로 연결해 한 결과로 합치는 작업이다.
영화관 티켓(영화 정보)과 회원증(회원 정보)을 회원번호라는 공통 키로 매칭해 "누가 어떤 영화를 봤는지" 알아내는 것과 같다.

개념 도식화 조인의 기본 원리

조인은 모델링 단계의 관계가 SQL 단에서 실제로 사용되는 방식이다. 두 테이블은 공통 키(외래키 FK)를 따라가며 행을 짝짓는다. 이론적 배경은 관계와 조인의 이해 참고.

-- LEFT OUTER (왼쪽 다)
SELECT M.NAME, O.ORDER_ID
FROM   MEMBER M LEFT OUTER JOIN ORDERS O
       ON M.MEMBER_ID = O.MEMBER_ID;

-- Oracle 전통 방식 (+) 기호
SELECT M.NAME, O.ORDER_ID
FROM   MEMBER M, ORDERS O
WHERE  M.MEMBER_ID = O.MEMBER_ID(+);   -- (+)는 매칭 안 될 때 NULL로 보충될 쪽(없을 수 있는 쪽)에 붙임

조인 종류 — 벤 다이어그램

INNER JOIN
A ∩ B
양쪽에 모두 매칭되는 행만
LEFT OUTER
A 모두 + 매칭되는 B
매칭 안 되면 NULL
RIGHT OUTER
B 모두 + 매칭되는 A
매칭 안 되면 NULL
FULL OUTER
A ∪ B 모두
없는 쪽은 NULL
CROSS JOIN
A의 모든 행 × B의 모든 행

조인 조건을 빼먹어도 발생하므로 의도치 않으면 위험하다.

SQL 실전 다양한 조인 

-- INNER JOIN
SELECT E.NAME, D.DEPT_NAME
FROM   EMP E JOIN DEPT D ON E.DEPT_ID = D.DEPT_ID;

-- 3개 테이블 조인
SELECT E.NAME, D.DEPT_NAME, L.CITY
FROM   EMP E
       JOIN DEPT D     ON E.DEPT_ID = D.DEPT_ID
       JOIN LOCATION L ON D.LOC_ID  = L.LOC_ID;

-- LEFT OUTER JOIN
SELECT M.NAME, O.ORDER_ID
FROM   MEMBER M LEFT JOIN ORDERS O ON M.MEMBER_ID = O.MEMBER_ID;

Before & After 조인 종류별 결과 행 차이

INNER 조인은 양쪽 모두에 매칭되는 행만 남기므로 박과 개발부가 동시에 사라진다. LEFT/RIGHT OUTER는 기준이 되는 쪽을 다 살리고 반대쪽이 비면 NULL을 채우며, FULL OUTER는 양쪽 모두를 살린다. "어느 쪽에 매칭이 없는 데이터까지 보고 싶은가"가 INNER vs OUTER 선택 기준이며, OUTER 조인 후 WHERE에 비기준 컬럼 조건을 걸면 NULL 행이 도로 빠지므로 추가 조건은 ON 절에 두는 것이 안전하다.
