GROUP BY, HAVING 절

행 단위 묶기 · 그룹 단위 필터 · 실행 순서 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

핵심 요약 정의

GROUP BY는 데이터를 그룹별로 묶는 절, HAVING은 묶인 그룹에 조건을 거는 절이다.
영수증 50장을 "분류별로 묶어 합계(GROUP BY 분류)" → "합계 10만원 넘는 분류만(HAVING 합계 > 10만)"으로 거르는 것과 같다.

실행 순서: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

GROUP BY의 핵심 규칙

GROUP BY에 명시되지 않은 컬럼은 SELECT 절에 그대로 쓸 수 없다. 집계함수로만 사용 가능하다.

-- 잘못된 쿼리
SELECT DEPT_ID, NAME, AVG(SAL)   -- NAME이 GROUP BY에 없음
FROM   EMP
GROUP BY DEPT_ID;

-- 옳은 쿼리
SELECT DEPT_ID, AVG(SAL)
FROM   EMP
GROUP BY DEPT_ID;

집계 함수 복습

GROUP BY와 함께 쓰이는 그룹함수의 기본형. 행 단위 분석이 필요하면 윈도우함수로 확장한다.

함수설명
COUNT(*)행 수(NULL 포함)
COUNT(컬럼)NULL 제외 행 수
SUM(컬럼)합
AVG(컬럼)평균
MAX/MIN(컬럼)최대/최소

비교 WHERE vs HAVING

WHERE 절이 행 단위 필터라면, HAVING은 그룹 단위 필터다.

WHERE
행 단위 필터
적용 시점: 그룹화 전 · 집계함수 불가
예) WHERE SAL > 3000
HAVING
그룹 단위 필터
적용 시점: 그룹화 후 · 집계함수 가능
예) HAVING AVG(SAL) > 3000
-- 잘못된 예: WHERE에 집계함수
SELECT DEPT_ID, AVG(SAL)
FROM   EMP
WHERE  AVG(SAL) > 3000;     -- 에러

-- 옳은 예: HAVING에 집계함수
SELECT DEPT_ID, AVG(SAL)
FROM   EMP
GROUP BY DEPT_ID
HAVING AVG(SAL) > 3000;

SELECT  DEPT_ID,
        COUNT(*)    AS CNT,
        AVG(SAL)    AS AVG_SAL
FROM    EMP
GROUP BY DEPT_ID;

-- 부서별 평균급여가 3500 이상인 부서만
SELECT  DEPT_ID, AVG(SAL)
FROM    EMP
GROUP BY DEPT_ID
HAVING  AVG(SAL) >= 3500;

-- WHERE + GROUP BY + HAVING 조합
SELECT  DEPT_ID, AVG(SAL)
FROM    EMP
WHERE   HIRE_DATE >= DATE '2020-01-01'   -- 2020년 이후 입사자만
GROUP BY DEPT_ID
HAVING  COUNT(*) >= 3;                   -- 3명 이상인 부서

GROUP BY는 행을 키 단위로 접어 한 그룹당 한 행으로 만들고, 그 위에서 집계 함수가 동작한다. 따라서 평균급여 같은 집계 결과를 조건으로 걸려면 행 단위인 WHERE가 아니라 그룹 단위인 HAVING을 써야 한다. "어떤 행을 걸러야 하나"는 WHERE, "묶은 결과 중 어떤 그룹을 남기나"는 HAVING — 필터를 어느 단계에 둘지를 먼저 정한 뒤 쿼리를 짜는 것이 안전하다.
