집합 연산자 (Set Operators)

두 개 이상 SELECT 결과를 합치거나 비교 · UNION · INTERSECT · MINUS

핵심 요약 정의

집합 연산자는 두 개 이상의 SELECT 결과를 합치거나 비교하는 도구다. 합집합(UNION), 교집합(INTERSECT), 차집합(MINUS).
도시락 A={김밥,사과,우유}와 B={사과,빵,우유} → UNION={김밥,사과,우유,빵}, INTERSECT={사과,우유}, MINUS(A-B)={김밥}.

개념 도식화 4가지 집합 연산자 

A = { 김, 이, 박 }      B = { 이, 박, 최 }

UNION       (A ∪ B, 중복 제거)  →  { 김, 이, 박, 최 }
UNION ALL   (A + B, 중복 유지)  →  { 김, 이, 박, 이, 박, 최 }
INTERSECT   (A ∩ B, 교집합)     →  { 이, 박 }
MINUS       (A − B, 차집합)     →  { 김 }       (A 에만 있는 것)

벤 다이어그램으로 보는 4가지 집합 연산자

Before & After UNION / UNION ALL / INTERSECT / MINUS

본사(EMP_A)와 지사(EMP_B) 두 명단을 합치거나 비교하는 상황. 두 표에는 "이"와 "박"이 양쪽 모두에 들어 있고, "김"은 A에만, "최"는 B에만 있다. 같은 데이터를 네 가지 집합 연산자(UNION/UNION ALL/INTERSECT/MINUS)에 넣었을 때 결과가 어떻게 갈라지는지 비교한다.

같은 두 입력에서 4가지 결과가 갈라지는 이유는 "중복을 어떻게 다루느냐"와 "어느 쪽 기준으로 비교하느냐"가 연산마다 다르기 때문이다. UNION은 중복을 제거하기 위해 정렬을 한 번 더 거치므로 행 수가 줄고, UNION ALL은 그 단계를 건너뛰어 그대로 이어붙인다. INTERSECT는 양쪽 모두에 있는 값만, MINUS는 A에만 있는 값만 남긴다. 따라서 "합칠 때 중복이 의미가 있는가" "두 집합의 공통 부분만 보고 싶은가" "한쪽에만 있는 것을 추리는가"를 먼저 묻고 연산자를 고르는 것이 핵심이다.

UNION vs UNION ALL 성능 차이

비교UNIONUNION ALL
중복 제거함안 함
정렬 작업일어남(중복 제거 위해)안 일어남
성능느림빠름
권장중복 가능성이 있을 때중복 없거나 그대로 둬도 될 때

중복이 절대 없다고 확신하면 UNION ALL을 사용해 성능을 높인다. 두 결과를 "행 단위로 이어붙이는" 집합 연산자와 달리 조인은 컬럼을 옆으로 붙이고, 서브쿼리는 메인쿼리에 값 하나를 공급한다는 점에서 역할이 다르다.

다중 컬럼 집합 연산

SELECT NAME, DEPT_ID, SAL FROM EMP_A
UNION
SELECT NAME, DEPT_ID, SAL FROM EMP_B;

모든 컬럼 값이 일치할 때만 중복으로 간주된다.
