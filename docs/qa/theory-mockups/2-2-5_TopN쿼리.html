Top N 쿼리

상위 N개를 뽑는 4가지 방법 · ROWNUM · FETCH FIRST · TOP · ROW_NUMBER

핵심 요약 정의

Top N 쿼리는 상위 N개 행만 뽑는 쿼리다(예: 매출 상위 10개 상품, 최신 5건의 주문).

개념 도식화 Top N의 4가지 방법

ROWNUM
Oracle ROWNUM
의사 컬럼 · 정렬 전 매겨짐 · 인라인뷰 필수
FETCH
표준 FETCH FIRST
Oracle 12c+ · OFFSET · WITH TIES · PERCENT
TOP
MS-SQL TOP
SELECT TOP n · TOP n WITH TIES
ROW#
윈도우 함수
ROW_NUMBER() OVER · PARTITION BY로 그룹별 가능

실행 순서 — 정렬 → Top N 적용

STEP 1
원본 테이블 EMP 스캔
STEP 2
ORDER BY SAL DESC
정렬 먼저
STEP 3
번호 매김
ROWNUM · ROW_NUMBER()
STEP 4
상위 N개 자르기
WHERE RN <= N

ROWNUM 함정의 본질이 여기 있다 — STEP 2(정렬) 전에 STEP 3(번호)이 먼저 매겨지면 의도와 다른 5명이 잘려 나온다. 그래서 인라인뷰로 정렬을 먼저 끝내야 한다.

SQL 실전 방식별 구현

Oracle ROWNUM

ROWNUM의 함정

ROWNUM은 ORDER BY 적용 전에 매겨지므로 정렬을 먼저 한 인라인 뷰를 감싸야 한다.

-- 잘못된 예: 정렬 전에 ROWNUM이 매겨짐
SELECT *
FROM   EMP
WHERE  ROWNUM <= 5
ORDER BY SAL DESC;     -- 5개 추출 후 정렬되어 의도와 다름

-- 올바른 예: 인라인 뷰로 정렬 먼저
SELECT *
FROM   (SELECT * FROM EMP ORDER BY SAL DESC)
WHERE  ROWNUM <= 5;
조건결과
ROWNUM = 1가능
ROWNUM <= 5가능
ROWNUM = 5결과 없음
ROWNUM > 5결과 없음

ROWNUM은 1부터 시작하므로 "5번째만"을 ROWNUM = 5로 표현할 수 없다.

표준 FETCH FIRST (Oracle 12c+)

EMP — 이 5000 / 박 4500 / 최 4500 (박·최 SAL 동률) 기준. ROWS ONLY와 WITH TIES 차이를 명확히 보려면 상위 2개로 비교.

-- 상위 2개 (정확히 N행)
SELECT *
FROM   EMP
ORDER BY SAL DESC
FETCH FIRST 2 ROWS ONLY;

↓ 결과 (2행) — 4500 동률 중 한 명만 임의로 포함(비결정적)

NAMESAL
이5000
박 또는 최4500
 
-- 상위 2개 (동률 포함)
SELECT *
FROM   EMP
ORDER BY SAL DESC
FETCH FIRST 2 ROWS WITH TIES;     -- 마지막 행 동률은 모두 포함

-- 상위 10%(백분율)
SELECT *
FROM   EMP
ORDER BY SAL DESC
FETCH FIRST 10 PERCENT ROWS ONLY;

↓ WITH TIES 결과 — 4500 동률 두 명 모두 포함되어 3행

NAMESAL
이5000
박4500
최4500

→ ROWS ONLY는 정확히 N행(동률은 잘림), WITH TIES는 마지막 N등과 동률인 행을 모두 포함해 N+α행이 될 수 있다.

옵션의미
FETCH FIRST n ROWS ONLY정확히 n개
FETCH FIRST n ROWS WITH TIESn등 동률은 모두 포함
OFFSET n ROWSn개 건너뛰고

MS-SQL TOP

SELECT TOP 5 *
FROM   EMP
ORDER BY SAL DESC;

-- 동률 포함
SELECT TOP 5 WITH TIES *
FROM   EMP
ORDER BY SAL DESC;

윈도우 함수 — 부서별 Top N

-- 부서별 급여 상위 3명
SELECT *
FROM   (SELECT NAME, DEPT_ID, SAL,
               ROW_NUMBER() OVER (PARTITION BY DEPT_ID ORDER BY SAL DESC) AS RN
        FROM   EMP)
WHERE  RN <= 3;

페이징(Pagination)

"1페이지: 1-10번째, 2페이지: 11-20번째..."

Oracle

-- 11~20번째
SELECT *
FROM   (SELECT ROWNUM RN, X.*
        FROM   (SELECT * FROM EMP ORDER BY SAL DESC) X
        WHERE  ROWNUM <= 20)
WHERE  RN >= 11;

표준 (Oracle 12c+)

SELECT *
FROM   EMP
ORDER BY SAL DESC
OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY;

Before & After 동률이 들어오면 갈라진다

EMP 5명에서 급여 상위 3명을 뽑는 상황. 박·최가 4500으로 동률이라는 점이 핵심 차이를 만든다. 같은 "Top 3" 요구라도 ROWNUM 기반(정확히 3명)과 WITH TIES(동률 모두 포함)가 어떻게 갈라지는지 비교한다.
