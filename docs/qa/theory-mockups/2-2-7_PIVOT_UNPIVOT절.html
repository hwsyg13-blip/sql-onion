PIVOT 절과 UNPIVOT 절

데이터 모양 변환 · 세로↔가로 · 집계 함수 필수 · CASE WHEN 흉내

핵심 요약 정의

PIVOT은 세로 데이터를 가로로, UNPIVOT은 가로 데이터를 세로로 바꾼다. 데이터 모양 변환 도구다.
"(김철수, 수학, 3) / (김철수, 영어, 2)" 같은 세로 카드 형태를 "김철수 | 수학3 | 영어2"의 가로 엑셀 표로 펼치는 작업이 PIVOT.

개념 도식화 PIVOT vs UNPIVOT

↕→↔
PIVOT (세로 → 가로)
행을 컬럼으로 펼침. 집계함수 필수. 매칭 안 되는 칸은 NULL
↔→↕
UNPIVOT (가로 → 세로)
컬럼을 행으로 접음. 기본 NULL 제외, INCLUDE NULLS로 포함

PIVOT과 UNPIVOT은 형식상 서로 역연산이지만, PIVOT은 집계함수가 끼고 UNPIVOT은 NULL을 기본으로 버린다는 비대칭이 있다.

PIVOT 절 — 세로 → 가로

문법

SELECT  *
FROM    원본테이블
        PIVOT (
            집계함수(값컬럼)
            FOR  변환대상컬럼 IN ('값1' AS 별칭1, '값2' AS 별칭2, ...)
        );

UNPIVOT 절 — 가로 → 세로

문법

SELECT  *

            값컬럼
            FOR 새컬럼명 IN (가로컬럼1 AS '값1', 가로컬럼2 AS '값2', ...)
        );

→ 가로의 수학·영어·과학 컬럼이 SUBJECT 값으로 접히고, 그 점수가 POINT 컬럼으로 풀린다. 1행이 3행으로 늘어남.

CASE WHEN으로 PIVOT 흉내내기 (전통 방식)

PIVOT 절 없이도 같은 결과를 만들 수 있다.

SUM(CASE WHEN ...)
조건별로 더하는 컬럼을 만든다
SUM(CASE WHEN SUBJECT='수학' THEN POINT END)
GROUP BY
행 키를 묶어 한 줄로 모은다
GROUP BY MEMBER
ROLLUP / CUBE
소계까지 함께 뽑고 싶을 때
GROUP BY ROLLUP(MEMBER)
SELECT  MEMBER,
        SUM(CASE WHEN SUBJECT = '수학' THEN POINT END) AS 수학,
        SUM(CASE WHEN SUBJECT = '영어' THEN POINT END) AS 영어,
        SUM(CASE WHEN SUBJECT = '과학' THEN POINT END) AS 과학
FROM    SCORE
GROUP BY MEMBER;

시험에서 단골: PIVOT 절을 모르고도 CASE + GROUP BY로 같은 효과를 낼 수 있다(소계까지 함께 뽑고 싶으면 그룹 함수의 ROLLUP/CUBE를 결합한다).

Before & After CASE 방식과 PIVOT 절 비교

분기·카테고리·매출이 세로로 쌓인 SALES 표를 분기별 가로 보고서로 바꾸는 상황. Q2에는 카테고리 B 매출이 없다는 점이 핵심으로, 이 빈 칸이 결과에서 NULL로 처리된다. 같은 변환을 Oracle PIVOT 절과 전통적인 CASE WHEN + GROUP BY 방식으로 동시에 표현해 비교한다.

두 방식의 결과가 같은 이유는 PIVOT 절이 사실상 "카테고리별 SUM(CASE WHEN ...)"을 분기 GROUP BY로 묶는 동작을 문법적으로 단순화한 것이기 때문이다. Q2의 B 칸이 NULL이 되는 것도 같은 메커니즘으로, 매칭되는 원본 행이 없어 SUM의 입력이 비어 있기 때문이다. PIVOT은 IN 절에 변환할 값을 명시적으로 나열해야 하므로 "어떤 컬럼이 만들어질지"를 미리 알아야 하고, CASE 방식은 분기 컬럼을 동적으로 조립할 수 있어 더 유연하다는 점이 표현력의 차이로 남는다.
