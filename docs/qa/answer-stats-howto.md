# 문항별 정답률 보는 법

사이트는 로그인 없이 운영되어 풀이 기록이 각자 브라우저에만 남는다. 실제 사용자 전체의 문항별 정답률을 보려고 **답을 고른 문항마다 GA4 이벤트를 하나씩** 보낸다 (2026-11-02~).

| 이벤트 | 매개변수 | 값 |
|---|---|---|
| `question_answer` | `qid` | 기출 `R57-2-45` (57회 2과목 45번), 모의고사 풀 `M1209` (사이트에 보이는 번호) |
| | `correct` | 1 정답 / 0 오답 |
| | `chosen` | 고른 보기 번호 1~4 |
| | `mode` | `exam` 기출 CBT · `mock` 실전 모의고사 · `endless` 무한 퀴즈 |

답을 고르지 않고 넘긴 문항은 보내지 않는다. CBT·모의고사는 **제출할 때**, 무한 퀴즈는 **채점할 때** 보낸다.

## 1. 처음 한 번 — GA4 에 맞춤 측정기준 등록 (사용자, 약 2분)

GA4 는 등록한 날부터의 데이터만 보고서에 보여 준다. 배포 직후에 등록할수록 데이터가 빨리 쌓인다.

1. GA4 → 관리 → 데이터 표시 → **맞춤 정의** → 맞춤 측정기준 만들기
2. 아래 3개를 만든다 (범위: **이벤트**)

| 측정기준 이름 | 이벤트 매개변수 |
|---|---|
| 문항 ID | `qid` |
| 정답 여부 | `correct` |
| 고른 보기 | `chosen` |

## 2. 데이터 내려받기 (1~2주에 한 번)

1. GA4 → 탐색 → **자유 형식**
2. 측정기준: 문항 ID, 정답 여부, 고른 보기 / 측정항목: **이벤트 수**
3. 필터: 이벤트 이름 = `question_answer`, 기간: 최근 30일 등
4. 행에 세 측정기준, 값에 이벤트 수 → 표시 행 수를 최대로 → 오른쪽 위 **내보내기 → CSV**
5. 받은 CSV 를 Google Drive 에 올리고 에이전트에게 파일 이름을 알려 주면 된다 (Drive 커넥터로 읽는다)

## 3. 재점검 목록 만들기 (에이전트)

```bash
node scripts/low-accuracy-report.mjs <받은 CSV> --threshold 25 --min 20
```

- 정답률 25% 미만 + 응답 20건 이상인 문항을 `docs/qa/low-accuracy-<날짜>.md` 로 정리 (가장 많이 고른 오답 포함)
- `scripts/audit/low-accuracy.json` 이 생기면 `check-question-quality.mjs` 가 점검 전 문항을 `LOW_ACCURACY` 경고로 계속 보여 준다
- 점검: 직접 풀어 보고 → 정답이 하나로 나오는지, 많이 고른 오답이 사실은 맞는 답은 아닌지, 자료·보기 표기 오류, 해설이 그 오답을 설명하는지 확인
- 고쳤으면 PR. 원래 어려운 문항이면 `scripts/audit/low-accuracy-reviewed.json` 에 `{"R57-2-45": "점검 사유"}` 로 기록 → 경고에서 빠진다
