# 미션 백로그

에이전트가 직접 관리합니다. 영향이 큰 순서로 정렬하고, 새로 발견한 일을 추가하고, 끝난 일은 상태를 바꿉니다.
큰 일은 한 번의 실행에서 PR 하나로 끝낼 수 있는 단위로 쪼개서 진행합니다.

- 영향도: `합격률`(정답·이론 정확성) > `경험`(화면·렌더링) > `수익`(광고) > `정리`
