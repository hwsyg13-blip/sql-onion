## 1. R58 2과목 28번 — 제보 264건 — VALID (정답 키 오류)
- 제보 핵심: "정답이 1번인데 2번으로 표시된다"
- 검증: EMP = (11,1002) (10,1002) (11,1004) (NULL,1003).
  `ORDER BY EMPNO DESC NULLS LAST, DEPTNO ASC FETCH FIRST 3` → EMPNO 11 중 DEPTNO 오름차순이므로 (11,1002), (11,1004), (10,1002).
  이는 선택지 ①「11 1002 / 11 1004 / 10 1002」과 일치. 현재 correctIndex=1(②)은 오답.
- 해설도 오류: "그중 DEPTNO 오름차순으로 1002가 뒤에 온다" (실제로는 앞).
- 수정안: `correctIndex: 0`, 해설 →
  "EMPNO 내림차순(NULLS LAST)이므로 11, 11, 10 순이고, EMPNO가 같은 11 중에서는 DEPTNO 오름차순이라 1002가 먼저, 1004가 나중에 온다. 상위 3건은 (11,1002), (11,1004), (10,1002)로 ①번이다."

## 2. R58 2과목 32번 — 제보 65건 (이 중 2건은 다른 문항 제목) — VALID (정답 2개)
- 제보 핵심: "㉠㉡㉣ 모두 X라 1번, 3번이 중복 정답"
- 검증: ㉠ NVL(NULL,'X')=X, ㉡ COALESCE(NULL,'X')=X, ㉢ NULLIF('X','X')=NULL, ㉣ NULLIF('X','Y')=X.
  같은 결과 쌍: ㉠㉡, ㉡㉣ (㉠㉣도 동일) → 선택지 ①「㉠과 ㉡」, ③「㉡과 ㉣」이 모두 옳음.
- 수정안(원문 미확인 — 전문가 확인 후 적용): ㉣을 `SELECT NVL('Y', 'X')`(결과 Y)로 변경하면 정답이 ①만 남음.
  해설에 "NVL('Y','X')는 첫 인자가 NULL이 아니므로 Y" 추가.
- 제목이 "아래 SQL의 결과로 옳은 것은?"인 2건은 옛 번호 체계의 제보로 보이며 이 문항과 무관 (CANT_FIND 처리).

## 3. R58 2과목 44번 — 제보 80건 — VALID (정답 2개)
- 제보 핵심: "2번, 3번 복수정답"
- 검증: ② "ROW_NUMBER는 동일 값에도 항상 서로 다른 순번을 부여한다" 옳음.
  ③ "RANK와 DENSE_RANK는 동일 값에 동일 순위를 부여한다는 점은 같다" 역시 옳음. ①, ④는 틀림.
- 수정안: ③을 "RANK와 DENSE_RANK는 동일 값 다음 순위를 건너뛴다는 점이 같다."(DENSE_RANK는 건너뛰지 않으므로 틀림)로 교체.
  correctIndex=1 유지. 해설에 "DENSE_RANK는 다음 순위를 건너뛰지 않는다" 추가.

## 5. R59 2과목 25번 — 제보 93건 — VALID (옳지 않은 것 3개)
- 제보 핵심: "옳지 않은 것이 3개(①②④)이다. '옳은 것'으로 바꾸고 답을 ③으로"
- 검증: CTAS는 컬럼 타입과 NOT NULL은 전달하고 PK/FK 등 제약은 전달하지 않음.
  ① 재정의 필요(거짓) ② NOT NULL 미전달(거짓) ③ PK/FK 미전달(참) ④ 타입 미전달(거짓).
  "옳지 않은 것"이면 정답이 3개가 되어 문제가 성립하지 않음. 현재 해설도 ①, ②, ④가 틀렸다고 설명함.
- 수정안: title →「CTAS(CREATE TABLE AS SELECT)에 대한 설명 중 옳은 것은?」, `correctIndex: 2`, 해설 →
  "CTAS는 컬럼 타입과 NOT NULL 제약은 그대로 전달하지만 기본키·외래키 등 다른 제약은 전달하지 않는다. 따라서 ③이 옳은 설명이다."

## 6. R60 1과목 3번 — 제보 61건 — VALID (옳지 않은 것 2개)
- 제보 핵심: "②도 틀린 설명이다(속성에는 하나의 값). 2, 3번 복수정답"
- 검증: 속성에는 하나의 값만 들어가므로 ② "두 개 이상의 값이 들어갈 수 있다"는 거짓.
  ③ "인스턴스는 두 가지의 속성값을 가진다"도 거짓 → 옳지 않은 것이 2개.
- 수정안: ②를 "하나의 속성에는 하나의 값만 들어갈 수 있다."로 교체(제보자 다수가 원문이라고 지적). correctIndex=2 유지.
  해설에 "속성은 하나의 속성값만 가진다(원자값)" 추가.

## 7. R57 2과목 48번 — 제보 52건 — NEEDS_EXPERT (문제 복원 필요)
- 제보 핵심: "(ㄱ)과 X가 보이지 않는다. 풀 수 없다"
- 검증: 보기가 `SELECT * FROM 회원 M ( ㄱ )`뿐이고 (ㄱ)에 들어갈 내용과 X 정의가 없음. 선택지는 이 정의를 전제로 함.
  해설로 추정하면 (ㄱ)은 `WHERE NOT EXISTS (SELECT X FROM 탈퇴 T WHERE T.회원ID = M.회원ID)`로 보이나 원문 확인 없이는 확정할 수 없음.
- 필요: 원문(기출 복원본)에서 보기 SQL 확인 → 확인 후 references 복원.
