## 🚨 P0 — 런치 전 반드시 고쳐야 하는 것

### 1. **프로덕션에 Supabase 환경변수 없음**
- 콘솔 경고: `[supabase] VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY 가 설정되어 있지 않아요. ... 지금은 로그인 없이 둘러보는 모드로 동작합니다.`
- **영향**: 로그인 불가 → 진도 저장·복습 큐·Pro 결제·모든 개인화 기능 죽음. 이 상태로는 수익화 0원.
- **담당**: 사용자(당신이 직접 Vercel에 변수 추가) — Backend 에이전트는 코드 수정 불필요.
- **액션**: Vercel 대시보드 → Settings → Environment Variables → `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 추가 (Production/Preview/Development 모두). 재배포 후 콘솔 경고 사라지는지 확인.

### 2. **광고 placeholder 텍스트가 사용자에게 노출**
- CBT 화면 하단 `광고 영역 · CBT_BOTTOM`, 기출 리스트 하단 `광고 영역 · EXAMS_BOTTOM` 같은 문자열이 **그대로 보임**.
- 기대 동작(`SETUP.md §8-4`): `VITE_ADSENSE_CLIENT` 없으면 `<AdSlot>` 은 아무것도 렌더링하지 않아야 함.
- **가설**: `VITE_ADSENSE_CLIENT` 에 빈 문자열이나 placeholder 값이 들어있거나, `AdSlot` 컴포넌트의 조건 분기가 텍스트 fallback을 남기고 있음.
- **담당**: Frontend — `src/components/AdSlot.tsx` 점검. 환경변수 미설정 시 `return null` 인지 확인.
- **확인 방법**: Vercel 환경변수에서 `VITE_ADSENSE_CLIENT` 제거 후 재배포.

### 3. **CBT 문제 본문에 마크다운 `**` 이 raw 로 렌더링**
- 제60회 기출 문항 1 본문: `해당 엔터티는 업무 수행 과정에서 지속적으로 이벤트가 쌓이므로 **데이터가 자주 변경되고 저장되는 양 또한 매우 많다.**`
- 별표 두 개가 bold 로 바뀌지 않고 문자 그대로 출력됨.
- **영향**: 실제 시험 대비 학습 중인 사용자에게 **문제 퀄리티 떨어져 보임**. 신뢰도 직결.
- **담당**: Frontend (렌더러) + 백엔드/콘텐츠 (소스에서 제거 or 렌더 파이프라인 정비)
- **확인**: `src/data/rounds/round-60.ts` 의 `stem`/`passage` 필드 확인 → 마크다운 렌더러 파이프라인(react-markdown 등) 적용됐는지. 현재 의존성엔 마크다운 라이브러리가 안 들어있음 → 즉 스크립트 파이프라인에서 미리 HTML로 변환하든지, 런타임에서 별표 제거 or 강조 스팬으로 치환 필요.

## ⚠️ P1 — 사용성/신뢰도 타격

### 4. **다크 모드에서 브랜드 로고 "SQL" 부분이 보이지 않음**
- 로고는 "🧅 SQL 양파" 구조로 보이는데, 다크 배경에서 "SQL" 글자가 거의 안 보임(흰 배경 가정한 색).
- 양파 아이콘도 채도가 거의 사라짐.
- **담당**: Designer + Frontend — 다크 모드 전용 로고 색 토큰/SVG 변형 필요.

### 5. **CBT "나가기" 에 확인 다이얼로그 없음**
- 50문항 풀던 중 실수로 나가기 누르면 기출 리스트로 바로 복귀 → 답안/체크 상태 날아갈 가능성.
- **담당**: PO(정책 결정: 자동 저장 vs 확인 모달) → Frontend/Backend(자동 저장이면 Supabase `exam_sessions` 쓰기) → Designer(모달 카피) → QA.
- **최소 단가**: `confirm("풀던 답이 저장되지 않아요. 정말 나가시겠어요?")` 로 일단 방어막.

### 6. **3주 공부계획 상태 표시 불일치**
- "완료 일자 **4**/21일" 이라 했는데, 하단 DAY 카드엔 DAY 1 / DAY 2 / DAY 5 세 개만 체크됨.
- "현재 주차 1주차 / Day **1** 진행 중" 표시인데 DAY 1 에 이미 체크가 있음 ("진행 중"과 "완료"가 동시).
- DAY 3/4는 체크 없이 지나가고 DAY 5가 체크되어 있음 (순서 건너뜀).
- **담당**: PO(상태 정의서) → Frontend(로컬 상태 로직 검증) → QA(시나리오).

### 7. **기출 CBT 에 타이머 없음**
- 모의고사 "실전 모드" 는 90분 타이머를 약속(`모의고사` 탭 카피: "90분 타이머").
- 하지만 **기출 CBT(제60회 등)** 은 진행 표시만 있고 타이머 없음.
- 의도 (기출은 연습이라 자유 페이스) vs 누락? PO 확정 필요.
- **담당**: PO → Frontend.

### 8. **초기 진입 화면이 의외**
- `https://sql-onion.vercel.app/` 접속 시 **"엔터티" 이론 본문**이 바로 노출. 로고 옆 네비엔 홈 탭이 없음.
- 푸터엔 "홈" 링크가 있음 — 불일치.
- 비회원 랜딩이 바로 이론 본문이면 "이 서비스가 뭐하는 곳인지" 설명이 없어 이탈률 ↑.
- **담당**: PO(랜딩 정책) + Designer(hero 섹션) + Frontend.
- **제안**: 비로그인 시 가치 제안 + CTA("3주 계획 시작 / 기출 바로 풀기") hero 화면을 보여주고, 이론은 탭 눌러야 진입.

## 🔍 P2 — 개선 제안

### 9. 네비에 "홈" 탭이 없음
- 4개 탭: 3주 공부계획 / 이론 / 모의고사 / 기출문제. 로고 클릭이 홈일 거라 추정하지만 명시적 "홈" 항목이 없음.
- 모바일에서 특히 헷갈릴 수 있음 (로고가 작아서 탭 같아 보이지 않음).

### 10. BETA 뱃지 비인터랙티브
- 우측 상단 `BETA` 뱃지에 클릭해도 반응 없음. 최소 tooltip (예: "2026년 6월 정식 출시 예정. 버그 제보 환영!") 붙이면 사용자 신뢰 ↑.

### 11. 모의고사 AI 생성 약속
- "AI가 실제 시험 출제 비율대로 새로운 문제를 만들어요" — Supabase 미설정 상태에서 실제로 돌아가는지 의심. 백엔드 검증 필요.
- **담당**: Backend(AI 호출 경로 확인 — Edge Function? 클라이언트에서 직접 OpenAI 호출?) → QA.
- **보안**: 만약 클라이언트에서 직접 LLM API 호출하면 API 키 누출 위험. **시급히 체크**.

### 12. 푸터가 짧고 약함
- `개인정보처리방침 / 홈 / 3주계획 / 이론 / 모의고사 / 기출` 만 있음.
- 연락처·환불정책·이용약관·회사 정보(사업자번호) 없음 — 결제 서비스로 운영하려면 **법적 필수** (전자상거래법).
- **담당**: PO(법무 체크) → CS(카피) → Designer → Frontend.

### 13. 키보드 단축키 힌트 없음
- CBT 에서 숫자키 1~4 / ←→ 로 네비 가능하면 파워유저에 큰 가치. 현재는 반응 확인 안 해봄 (있어도 UI 힌트 없음).

### 14. 상태 정보 접근성
- OMR 답안지 칸에 "1번 문항, 아직 미응답" 같은 aria-label 있는지 불명. 스크린리더 사용자에겐 지금 몇 번 몇 점 상태인지 알기 어려움.

### 15. 페이지 타이틀 고정
- 모든 화면에서 `<title>` 이 `SQL양파 — SQLD 3주 합격 루틴` 으로 고정. 라우트별 타이틀 변경(`기출문제 · SQL양파`, `제60회 CBT · SQL양파`) 하면 검색·탭 구분 ↑.
